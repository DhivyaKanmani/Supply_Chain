
# DataCo Supply Chain Performance Dashboard | Python, MySQL & Power BI

## Project Overview

This project analyzes supply chain data to understand order performance, profitability, and logistics operations.

Python is used for data cleaning and preprocessing, MySQL is used for data storage and SQL-based analysis, and Power BI is used to create interactive dashboards and visualize key business insights.

## Key Features

- Customer, discount, order, and profit KPI analysis.
- Order trends and product performance analysis.
- Region-wise and category-wise profitability analysis.
- Shipping mode and delivery status analysis.
- Late delivery and logistics performance analysis.
- Interactive filters for exploring supply chain data.

## Tools Used

- Python (Pandas) – Data cleaning and preprocessing.
- MySQL – Data storage and SQL-based analysis.
- Microsoft Power BI – Dashboard development and data visualization.
